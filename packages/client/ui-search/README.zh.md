# @deepseek-ai/dsh-client-ui-search

[English](README.md) | 中文

## 概述

`dsh-client-ui-search` 在工作区之上放一个搜索框。输入即从客户端目录列出命中的工作区与会话，同时按 Host 给出的游标一页页读取已建索引的消息内容。结果按「工作区、会话、消息」分组；回车打开选中的工作区、会话或消息。面板对消息检索做防抖、取消被取代的读取，并在下一页加载期间保留上一页内容。

<a id="use-this-package"></a>
## 使用本包

在桌面窗口中任意位置按 ⌘F（Windows / Linux 为 Ctrl+F）。Web 端用 ⌘⌥F，因为那里 ⌘F 与 ⌘⇧F 分别属于浏览器的查找栏和既有的会话搜索；两个入口是同一个命令 `search.messages`，改键位即同时生效。

浮层持有四样状态：查询词、客户端目录给出的名称结果行、已读各页累积的消息行、以及选中项。它不持有传输状态——每次消息读取都走会话数据层，失败的调用被折成结果，面板据此渲染失败态并提供重试。

名称匹配是本地即时完成的：每次按键都会重新过滤工作区显示名与会话标题，因此消息读取还在防抖等待时，名称命中已经出现。命中工作区由工作区服务打开；命中会话或消息则打开该会话，消息会带上自己的位置，供会话视图落到那条消息。

<a id="understand-the-implementation"></a>
## 实现说明

`src/client/local.ts` 派生名称结果行：对工作区显示名与会话标题做大小写不敏感的子串匹配，工作区按 Host 顺序、会话按最近更新在前，并按工作区浏览器的规则排除空白会话、子代理会话与已归档会话。

`src/client/index.ts` 是插件本体：注册字典、快捷键与 `shell.overlay` 条目，把名称行排在 Host 消息行之前组合成结果，并持有防抖后的读取序列。序号计数器丢弃被新按键或关闭动作取代的旧回复，因此慢到的页永远覆盖不了新结果。

`src/client/state.ts` 承载面板状态、结果行联合类型与由线上类型派生的游标类型。`src/client/SearchPanel.tsx` 是纯展示层：状态快照与回调经插槽的 inject 面传入，它自己不持有任何服务。

分页跟随 Host：`nextCursor` 是不透明值，缺失即停止索取。滚动到列表底部只在序列处于完成态时请求下一页，因此待发的读取不会被重复触发。

<a id="model-experience"></a>
## 模型体验

无。本包只为人渲染搜索结果，不触碰提示词、消息、模式、流或工具结果；它展示的已索引内容本就存在于模型已经读到的会话记录中。

#### KV Cache 影响

无；本包从不组装或发送模型请求。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

- 名称匹配是对已载入的会话目录与工作区目录做客户端子串匹配，不匹配会话 id、工作区路径，也不匹配目录里没有列出的内容。
- 打开一条消息结果只打开它所属的会话。要落到命中的那条消息并高亮，需要有「事件 → 节点」的映射，而会话视图目前不暴露它；助手消息会合并进分组节点，一个 `seq` 并不对应某一个节点。
- 面板读取的是 Host 当前的索引状态。未被索引的会话由 coverage 字段报告，并呈现为「结果可能不全」的提示，而不会安静地漏掉。
- 消息结果是平铺的，没有按会话分组；分组方案已出图，暂缓。
- 归档的会话在所有分区中都不出现，与侧栏一致；暂无「包含已归档」选项。
- 摘要是 Host 返回的原文。命中区间索引的就是这份原文，所以任何去掉标记的呈现都需要先建位置映射，才能替换现在的字面渲染。
- 只有在 Host 的消息索引打开时本面板才挂载。现成的 Web profile 让索引保持关闭，因此该 profile 中这一行被禁用；要启用内容检索的部署，在覆盖 `openAt` 的同时加上这一行。

<a id="dev-note"></a>
### 开发备注

所有可见文案由字典持有，面板内没有字面文案。行内高亮来自 Host 返回的命中区间（已裁剪到摘要窗口之内），或来自 `local.ts` 为名称算出的命中区间；面板只负责把字符串切成片段，不会二次检索。
