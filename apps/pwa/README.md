# @deepseek-ai/dsh-pwa

English | [中文](README.zh.md)

Composition-layer PWA plugin over `dsh web`: it registers `/manifest.webmanifest` (shadowing the frontend's minimal static one with a full standalone-display manifest), `/sw.js` (network-first navigation with the cached shell as offline fallback), and the `/pwa/*` PNG icon set as named webserver routes, then injects the missing head references (theme color, apple-touch icon, service-worker registration) through the webserver index tap. The frontend build is untouched; with this plugin mounted, Chrome/Edge on desktop and Android offer "install app", and iOS Safari gets a proper home-screen icon.

## Mounting

The package declares a `dsh.bundle` patch, so adding it to a profile activates it as a layer — no flags afterwards:

```sh
pnpm --filter @deepseek-ai/dsh-pwa run build
pnpm dsh plugin --profile web add link:$(pwd)/apps/pwa
pnpm dsh web
```

Remove it with `pnpm dsh plugin --profile web remove @deepseek-ai/dsh-pwa`.

## Phones need a route to the server

The backend cannot run on a phone, so the phone client is this installable page served over the network. `dsh web` deliberately rejects `--host 0.0.0.0` (anyone reaching the port can run code as your user); [overlay/lan.patch.yml](overlay/lan.patch.yml) is the explicit opt-in that binds all interfaces anyway, for networks where every device is yours. Service-worker install additionally requires a secure context: `http://127.0.0.1` qualifies, a bare LAN `http://<ip>` does not — prefer a tailnet HTTPS route or a reverse proxy with a certificate; over plain LAN HTTP the page still works and Android falls back to a plain shortcut.

## Config

| key | default | meaning |
| --- | --- | --- |
| `appName` | `DeepSeek Harness` | install-prompt and OS app-list name |
| `shortName` | `dsh` | launcher-icon label |
| `themeColor` | `#10131a` | installed-window toolbar color |
| `backgroundColor` | `#10131a` | splash background |

Icons are shipped assets generated by `scripts/gen-icons.mjs` (deterministic, dependency-free); rerun it after editing the design and commit the PNGs.

## Known Limitations and Deferred Work

- The service worker caches only the index shell: offline opens show the app frame, but every API call needs the server. A deeper offline story is deliberately out of scope.
- Icon artwork is fixed at build time; `Config` covers manifest identity only.
